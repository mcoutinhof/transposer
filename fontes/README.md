# Fontes dos acordes

Quando o acorde original está numa destas fontes, o acorde novo sai nela também
(senão, numa das fontes padrão do PDF). Geradas por `ferramentas/gerar-fontes.sh`.

| Arquivo | Origem | Licença |
|---|---|---|
| `OpenSans-*.ttf` | Open Sans 1.10 (Google) | Apache 2.0, `LICENSE-OpenSans.txt` |
| `TransposerMono-*.ttf` | Liberation Mono 2.1.5 (Red Hat) | OFL 1.1, `OFL-TransposerMono.txt` |

Modificações: só ASCII e Latin-1, sem hinting nem tabelas de layout. Liberation Mono foi renomeada para TransposerMono porque
"Liberation" é nome reservado na OFL.
